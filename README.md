# Slovenia from Koper

An editorial guide to experiencing Slovenia from your cruise ship — not a shore excursion marketplace.

Built with Next.js 16 (static export) and deployed to Cloudflare Pages.

## Development

```bash
npm install
npm run dev
```

## Build & deploy

```bash
npm run build
npm run pages:deploy
```

## Editorial positioning

- Inspire first, recommend later
- Experiences over products
- Confidence over urgency
- Written like we'd advise our own parents
